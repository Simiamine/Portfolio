AirportProject (Scala)

Application de gestion d’aéroports

Application Scala permettant de parser trois fichiers CSV (pays, aéroports et pistes) et proposant des recherches par code ou nom approximatif, ainsi que la génération de rapports.

  • Parsing CSV via un parseur perso (pas de lib externe)
  • Fuzzy matching (nom partiel) grâce à me.xdrop.fuzzywuzzy
  • Fonctionnalités de rapport (Top 10 pays avec plus/moins d’aéroports, etc.)
  • Gestion d’interface graphique JavaFX et d’un mode CLI
  • Futures Scala pour le calcul parallèle de certains rapports

Le projet peut être lancé via sbt clean compile run (GUI par défaut) ou en modifiant la mainClass pour exécuter la version CLI. Des tests sont disponibles via sbt test.

Diabetes Machine Learning

Classification du diabète avec scikit-learn

Projet mené à EFREI pour prédire l’apparition du diabète à partir du dataset Pima Indians Diabetes. J’ai réalisé une analyse exploratoire (EDA), un prétraitement (valeurs manquantes, standardisation) et implémenté plusieurs modèles de classification :

  • Régression Logistique
  • Arbre de Décision
  • Réseau de Neurones (MLP)

J’ai ensuite optimisé les hyperparamètres (Grid Search) et comparé accuracy, precision, recall, F1-score et matrices de confusion. Le Réseau de Neurones optimisé a finalement présenté les meilleures performances pour détecter les patients diabétiques.
